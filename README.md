# 🌱 Eco-Rebuild: Innovación e Infraestructura Sostenible (ODS 9)

Videojuego 3D de simulación y gestión en tercera persona desarrollado con **Three.js** y **Vite**.

El objetivo es transformar una región gris, contaminada e incomunicada en un polo tecnológico y sostenible, cumpliendo los principios del **ODS 9: Industria, Innovación e Infraestructura**.

---

## 🎮 Mecánicas Principales (Economía Circular)

Los materiales no se compran; se extraen de los desechos repartidos por el territorio:

1. **Terminal Eco-OS (Laptop del Taller)**:
   - Recepción de pedidos de las comunidades locales (antenas WiFi de largo alcance, carreteras de caucho reciclado, plantas solares, monitoreo fluvial IoT y puentes de acero ecológico).
   - Cada misión desbloquea transformaciones visibles en el mundo 3D y purifica el medio ambiente.

2. **Recolección en Vertederos**:
   - Desarmado de e-waste (celulares y laptops), placas madre, vigas de chatarra industrial, neumáticos usados, cables y baterías de ion-litio.

3. **Las Extractoras Ecológicas (Taller)**:
   - **Extractora Hidrometalúrgica**: Recupera Cobre Puro, Oro Tecnológico 24k y Silicio Solar.
   - **Despolimerizadora**: Procesa Caucho Recompuesto y Polímero Reforzado.
   - **Fundidora Solar por Inducción**: Funde Acero Estructural y purifica Litio con cero emisiones.

## 🕹️ Controles

| Tecla / Acción | Función |
| :--- | :--- |
| **W / A / S / D** o **Flechas** | Moverse en 3ª persona (la cámara se auto-orienta hacia tu dirección) |
| **Shift** | Correr rápido |
| **Espacio** | Saltar |
| **E** | Interactuar (abrir laptop, usar extractora, desarmar chatarra) |
| **T** | Abrir la terminal de pedidos y proyectos ODS 9 |
| **I** | Abrir la mochila e inventario |
| **Click + Arrastrar Ratón** | Inspección y rotación manual de la cámara orbital |
| **Rueda del Ratón** | Zoom in / Zoom out |

## 🚀 Instalación y Ejecución Local

1. Instalar dependencias:
```bash
npm install
```

2. Iniciar el servidor de desarrollo:
```bash
npm run dev
```
Abre en tu navegador: `http://localhost:5173/`

3. Compilar para producción (carpeta `dist/`):
```bash
npm run build
```
